# 水墨界面统一换皮设计

## 目标

把现有可用但风格分散的运行时界面统一为“宣纸卷轴、青灰水墨、朱砂点睛”的仙侠界面。第一轮只改善玩家最常打开的三类界面：人物对话、背包、任务与章节。玩法数据和既有快捷键保持不变。

## 视觉规范

### 色彩

| 用途 | 颜色 | 规则 |
| --- | --- | --- |
| 纸张底色 | 暖米白 | 所有主面板的阅读背景。 |
| 墨字与边线 | 深青灰 | 正文、边框、未选中标签。 |
| 青绿 | 竹青 | 可用资源、普通高亮、友好 NPC 名称。 |
| 朱砂 | 暗朱红 | 确认、关闭、任务目标、选中状态；只作小面积点缀。 |
| 淡墨 | 半透明灰褐 | 竹影、山形和角落装饰，不干扰文字。 |

### 组件

1. `InkPaperPanel`：九宫格可拉伸宣纸面板；四边墨线保持粗细，中央纹理可重复。
2. `InkSealButton`：朱砂圆印或方印按钮，包含普通、悬停、按下、不可用四种状态。
3. `InkTab`：书页页签；当前页使用竹青底与深墨字，未选中页降低对比度。
4. `InkGridSlot`：竹木边线的方形收纳格；空格显示淡墨纹理，物品格显示图标、数量、品质角标。
5. `InkDialogueFrame`：横向卷轴；左侧为头像位，右侧为 NPC 名称、对话正文、选项区域。

字体优先使用项目中可用的中文字体；若缺少专用书法字体，使用清晰的系统中文字体并以字号、行距、墨色营造气质，不引入需要授权确认的外部字体。

## 首批界面

### 对话框

- 位于屏幕下方，宽度约为屏幕的 78%，高度约为 28%。
- 左侧永远保留 NPC 头像框：没有立绘时显示淡墨剪影与身份文字，避免空白。
- 显示 NPC 名称、正文和一至三个可选回复；Enter 为继续，Esc 为关闭。
- 对话过程中冻结对话相关输入，不冻结界面动画；关闭后恢复原控制状态。

### 背包

- 保持 `B` 键及现有背包数据模型。
- 左栏为角色摘要与材料统计，中部为 5 列 x 4 行物品网格，右栏为选中物品说明。
- 竹材、竹笋先映射为明确的物品条目；未来装备、丹药、任务物品沿用相同格子和说明区。
- 格子是表现层，不持有物品数量或合成规则。

### 任务与章节

- 保持 `J` 键及已有任务进度来源。
- 收起状态显示在右侧的窄书签：章节名、当前目标和小型进度符号。
- 展开状态是一页任务簿：章题、地点、当前目标、已完成步骤和下一步指引。
- 章节完成、接受任务和目标更新使用短暂的朱砂印记提示，不使用大面积遮屏弹窗。

## 技术边界

1. 新增 `InkUiTheme` 作为颜色、尺寸、字体和九宫格资源的唯一来源；业务 HUD 不直接写具体色值。
2. 新增 `InkUiFactory` 负责创建面板、文字、按钮、页签与格子，避免每个 HUD 重复搭 Canvas 控件。
3. 现有 `AdventurePanelsHud`、`InventoryHud`、故事/对话入口只负责绑定数据与开关状态，逐步迁移到主题组件。
4. 第一轮可使用 AI 生成的透明 PNG 纸纹、边框、印章、格子和图标；所有资源放在项目专用 UI 目录，并保留无贴图的代码回退样式，避免资源导入失败时界面不可读。
5. Canvas 继续采用现有 `ScaleWithScreenSize` 约定；静态窗口与伤害飘字保持分 Canvas，避免高频飘字触发主界面重建。

## 资源清单

第一轮需要五类透明 PNG：可拉伸宣纸底、可拉伸墨线边框、朱砂印章、竹木格子、六个 64px 图标（背包、游历、地图、医馆、设置、关闭）。这些是主题资源，不绑定任何单一窗口。

## 验收

1. 1920x1080 与 1280x720 下，三类窗口没有文字溢出、按钮重叠或边框变形。
2. `B` 打开背包、`J` 打开任务；关闭方式与原行为兼容。
3. NPC 对话可显示缺省头像、长文本和至少两个选项。
4. 玩家可明显看出三个窗口属于同一套水墨界面。
5. 没有贴图或贴图导入失败时，窗口仍可读、可关闭且不影响游戏主循环。

## 不在本轮范围

- 重做主菜单、战斗 HUD、技能树、商店和医馆完整交易流程。
- 制作 NPC 全身立绘、人物 3D 模型、房屋模型或场景大地图。
- 改写背包、任务、战斗或存档的数据规则。
