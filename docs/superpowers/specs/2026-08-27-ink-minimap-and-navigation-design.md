# 水墨小地图与场景导航设计

日期：2026-08-27  
状态：待用户确认规格

## 目标

解决玩家在大幅背景贴图中缺少空间参照的问题，使玩家能够持续判断：

- 自己是否正在移动；
- 自己位于总地图的哪个区域；
- 前方是道路、事件节点还是地图边界；
- 怪物、NPC、商店和建筑相对于自己的方向。

本功能不替换现有水墨背景图，也不改变玩家移动速度、战斗内核或相机跟随规则。

## 玩家体验

右上角常驻一张小型水墨卷轴地图。地图显示完整世界边界、主要道路、玩家位置以及当前章节相关目标。玩家移动时，青色方向标在卷轴中连续移动；即使主画面暂时缺少参照物，也能看出位移。

玩家接近世界边缘时，卷轴对应边缘出现淡朱砂晕染，主画面显示短提示“前方无路”。提示有冷却，不会在玩家持续按住方向键时刷屏。

主场景道路两侧增加可识别的地标组：竹丛、石碑、竹筐、灯笼、路牌和小型建筑剪影。地标使用确定性布局，同一种子下位置不变，并为战斗区、NPC 对话区与道路中心保留清晰空间。

## 视觉方向

小地图采用“折角宣纸卷轴”，而不是圆形雷达：

- 底色：半透明旧宣纸；
- 边框：不规则深墨双线；
- 道路：低饱和灰褐墨线；
- 玩家：青绿色小箭头，并随最后朝向旋转；
- 普通怪物：小型暗红圆点；
- 章节怪物：朱砂印章形标记；
- NPC：淡金人物点；
- 商店：赭色屋檐图标；
- 当前任务：带呼吸效果的空心朱砂圈；
- 地图边缘反馈：短暂扩散的淡红墨迹。

小地图默认不显示文字图例，避免右上角拥挤。玩家靠近任务节点时，才在卷轴下沿显示一个简短中文名称。

## 架构

### MinimapProjection

纯 C# 坐标规则，负责把世界坐标转换为小地图归一化坐标。输入是世界尺寸与世界坐标，输出限制在 `[0, 1]` 范围。它不依赖 Canvas、相机或 GameObject，便于 EditMode 测试。

职责：

- 世界坐标到小地图坐标的换算；
- 世界边缘距离计算；
- 无效世界尺寸的安全回退；
- 地图图标边距钳制。

### MinimapMarker

场景实体向小地图公开的轻量标记组件。字段包括标记类型、稳定标识、是否常驻显示以及可选中文名称。敌人死亡或对象销毁后，图标自动移除。

标记类型固定为：玩家、普通怪、章节怪、NPC、商店、建筑、任务目标。竹子和普通石头不进入小地图，避免信息噪声。

### InkMinimapHud

独立的 Screen Space Overlay Canvas，排序层级位于普通 HUD 之上、弹出菜单之下。它只读取玩家位置、`WorldBuilder.WorldWidth/WorldHeight` 与当前有效标记，不写入游戏状态。

实现策略：

- 地图底板、边框、道路和图标在 Build 阶段一次创建；
- 玩家箭头每帧更新；
- 其他标记仅在注册、移动超过阈值或被销毁时更新；
- 不为每个图标创建独立 Canvas；
- 不在每帧执行全场景对象搜索。

### NavigationLandmarkPlan

纯规则生成道路两侧的地标位置。输入为 `FirstChapterLayout` 和地图种子，输出地标种类、位置、缩放和前后层级。规则必须避开：

- 道路中心通行带；
- 玩家出生留白区；
- 遇怪战斗区；
- NPC 对话区；
- 商店入口。

第一版使用项目已有水墨竹子、石头和运行时剪影组合；后续替换成正式 PNG 或 Blender 模型时，坐标规则和小地图接口保持不变。

### WorldBoundaryFeedback

读取玩家尝试位移前后的位置。当输入方向指向边界且位置被钳制时，触发一次边界反馈。该组件不改变 `PlayerController` 的边界规则，只消费一个只读的“本帧是否被边界阻挡”状态。

反馈包括：

- 小地图对应边缘的朱砂晕染；
- 主画面短文本“前方无路”；
- 轻微纸张摩擦音接口，第一版可无音频资源运行。

## 接入点

`WorldBuilder.BuildScene()` 在玩家、战斗和基础 HUD 建立后装配导航系统：

1. 创建 `InkMinimapHud`；
2. 注册玩家标记；
3. 注册现有敌人以及第一章任务怪；
4. 第一章运行时生成 NPC、商店和建筑时同步注册对应标记；
5. 构建道路地标；
6. 绑定边界反馈。

随机生成的敌人由生成器在创建和销毁时主动注册/注销，不允许小地图依赖每帧 `FindObjectsOfType`。

## 地图与遇怪节奏

第一章道路不再只有一个孤立怪物。第一版布置三个层次：

- 首个教学怪：单独出现，进入范围才激活；
- 道路巡逻组：两只普通怪，保持足够距离，不同时围攻初始玩家；
- 商店前安全区：不生成怪物，让 NPC、对话与购买能够稳定进行。

小地图只显示一定距离内的普通怪物；章节怪和当前任务节点常驻显示。这样既能导航，也不提前揭露整张地图的所有危险。

## 错误与降级

- 世界尺寸未初始化：小地图显示宣纸底板和“地图绘制中”，不抛异常；
- 玩家尚未生成：保留地图，隐藏玩家箭头并重试绑定；
- 标记对象销毁：下一次刷新安全移除；
- 中文字体不支持：图标仍可用，名称文本退化为空；
- 小地图资源加载失败：使用运行时生成的宣纸色块和墨线图标。

## 测试

### 自动测试

- 世界四角和中心能够正确投影；
- 超出世界范围的坐标会被钳制；
- 无效世界尺寸不会产生 NaN；
- 地标不会落入道路、战斗区、对话区或商店入口；
- 普通怪距离显示规则与章节怪常驻规则正确；
- 边界阻挡只在“有输入且位置被钳制”时触发；
- 连续顶住边界时提示遵守冷却。

### Unity 验收

1. 玩家从出生点向四个方向移动，小地图箭头连续变化；
2. 走到边界时出现对应方向的朱砂反馈与“前方无路”；
3. 场景中可看见至少五类道路参照物；
4. 首个教学怪、巡逻怪、NPC 和商店标记位置与实体一致；
5. 击杀怪物后红点消失；
6. 打开背包、技能等弹窗时，小地图不遮挡弹窗且停止响应点击；
7. 1280×720、1920×1080 与非 16:9 窗口下不与现有血条、调试区、底部按钮重叠。

## 本轮范围

本轮完成：常驻全图小地图、玩家与事件标记、边界反馈、第一章道路地标，以及第一章三段遇怪节奏的接入基础。

本轮不做：可缩放大地图、战争迷雾、地图传送、自定义地图标记、室内多楼层地图和完整导航寻路。
