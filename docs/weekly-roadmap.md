## 〇、执行前已定的几个决策（不征询，直接落地）

1. **渲染管线维持 Built-in**：当前工程已是 Built-in 渲染 + 2.5D 正交相机，已跑通竹林/水墨地面/雾。蓝图写的是「2D URP」，切 URP 对初学者无收益且风险高 → 记为**有意偏差**，不阻塞后续任何系统。
2. **内容决策权归你**：物品名、数值、剧情文本、技能伤害等一律走 **ScriptableObject 占位默认值**（我给一套能跑的默认数据），你后续在编辑器里调。我不替你定内容方向。
3. **保护资产红线（死守）**：女主骨骼 prefab/原图、程序化小怪、你本地在途改动一律**不碰、不删、不覆盖**；新内容一律**新增文件/目录**承载。
4. **不引入第三方包**：仅保留已硬依赖的 Unity 2D Animation 包。
5. **验证方式**：本环境无 Unity。我落地代码 + 提交（对象推送法），你本地 `Shuimo/Scene/Force Recompile` + PlayMode 验收。纯逻辑系统优先做成可 NUnit 自测，减少你验证负担。
6. **架构惯例沿用**：纯逻辑进 `Assets/Scripts/Systems/<Name>/` + `Xianxia.<Name>.asmdef`（noEngineReferences）；Unity 表现层进 `Assets/_Project/Scripts/Runtime/<Name>/` + `Xianxia.Unity.T2.<Name>.asmdef`。独立 asmdef 隔离编译风险。

## 第 1 周 · 地基收口：核心管理器 + 项目结构对齐

**对应蓝图**：阶段0（项目搭建 + 骨架 + 美术管线验证）

- [x] **主菜单 + 暂停 + 退出** 接线（MainMenuHud/PauseMenuHud 已存在，接 GameManager 状态）。

**数据驱动 / 留白**：事件类型、存档 schema 先定义骨架；具体数值/内容第2周起逐步填充。渲染管线定为 Built-in（见决策1）。

## 第 3 周 · 正魔值系统 + 性格系统

**对应蓝图**：阶段1.4–1.6（正魔值 / 性格 / 战斗验证）
**本周目标**：落地游戏灵魂系统——正魔值此消彼长 + 性格玩出来，并让它**真实影响战斗**。

**交付清单（纯逻辑 asmdef `Xianxia.Morality` + `Xianxia.Personality`）**
- [ ] **MoralityManager**：正道值↔魔道值 0–100 此消彼长；变更走事件。
- [ ] **战斗机制·克己 vs 拔刀**：普攻+留手=正道稳（低伤不涨魔）；杀招/重击+击杀=魔道涨（高伤魔+）。
- [ ] **正魔影响战斗参数**：正道高→防高攻抑心稳；魔道高→攻高防低有反噬。
- [ ] **魔道反噬**：用魔道技能/杀招概率反噬（掉血/掉防），魔道越高概率伤害越高；满 100%→入魔（反噬消失但"你不是你了"）。
- [ ] **贪婪诱惑机制**：魔道越高，"吸功/杀招"选项高亮越明显。
- [ ] **人性细节**：前几次吸功弹确认框，多次后不弹；首次给微妙心理暗示（非说教）。
- [ ] **侠道路线**：正魔中间区间解锁"侠"道（随心不滥杀）。
- [ ] **性格系统**：五大性格（悟性/冲动/隐忍/冷静/贪婪），**玩出来非开局选**；性格→战斗（冲动先手但不忍拔刀/隐忍受击蓄力/冷静命中抗幻/贪婪拾取多反噬高/悟性学技快识破）；性格×正魔联动（悟性低易被骗入魔）。
- [ ] **正魔墨条 UI**（墨色渐变，正清魔浓）+ **性格面板 UI**。
- [ ] **战斗验证场景升级**：感受"隐忍难打 vs 放开爽但入魔"张力 + 性格差异体感。

**数据驱动 / 留白**：反噬概率表、性格阈值、墨条配色走配置。

**本地一次性验收**
1. PlayMode：打怪时正魔值随"克己/拔刀"明显变化，墨条渐变正确。
2. 魔道拉高后放魔道技能出现反噬掉血；满魔后入魔态。
3. 性格值随战斗选择变化，并能在战斗参数/选项上体感（如冲动高时"忍了"变灰）。

## 第 5 周 · 水墨物理法则
